一、核心功能快速指南 (Quick Start Guide)

1. 什么是“信州大学 3+3 间歇快走法 (IWT)”？

由日本信州大学医学部能势博 (Hiroshi Nose) 教授与增木静江 (Shizue Masuki) 教授团队历时十余年临床验证的科学健走方案：

  • 免费开放标准处方：永久免费开放 「① 信州大学标准 3+3 间歇快走 30分钟」（快走 3 分钟约 70%–85% HRR / 120–135 SPM 与慢走恢复 3 分钟约 40% HRR / 95–105 SPM 循环交替），以及 3 款免费主题、3 款免费表盘、14 项实时生理指标、最近一次运动轨迹回放与高清海报生成。
  • 循证医学出处：应用内完整内置 19 篇 NIH PubMed 权威医学文献原文链接 供随时核验。

2. 后台持续节拍音频与户外后台定位说明 (Background Audio & Location)

  • 后台节拍与声景 (UIBackgroundModes: audio)：在首页或驾驶舱点击 “▶ 开始训练 (Start Workout)”（或开启顶部 “🌙 助眠” 剧场）后，即使您返回 iOS 主屏幕或锁屏息屏，48kHz 实时合成步频节拍器、和弦伴奏、阶段语音教练与夜间助眠声景均会无缝持续发声，并在系统控制中心与锁屏界面展示媒体播放控制卡片（支持与 Apple Music / Spotify / 播客智能混音闪避）。
  • 户外后台轨迹定位 (UIBackgroundModes: location)：在户外健走进行中退回后台或锁屏放入口袋时，系统状态栏会点亮蓝色后台定位胶囊图标，持续记录完整的户外 3+3 快慢走配速轨迹与里程；结束健走后后台定位立即自动关闭。
  • 静止自动暂停 (Auto-Pause)：首次安装默认处于关闭状态，方便室内原地踏步体验；户外过马路需自动暂停时可在驾驶舱一键开启。

3. 🌙 五源传感神经助眠剧场 4.0 (5-Sensor Sleep Sanctuary)

  • 点击主界面顶部的 “🌙 助眠 (Sleep)” 按钮进入深空助眠剧场：
  • 免费开放范围：免费开放「① 晚间深睡 · 脑波渐缓夹带」处方（20m / 30m）、前 3 款 48kHz 大师和弦、前 3 款自然声景 + 前 2 款脉冲、机身四源节律感知 + 2 款基础呼吸法（0.1Hz 共振、4-7-8 催眠），以及最近一次睡眠记录 100% 免费开放（含综合评分、6 维指标与 1x–30x 全息回放）。
  • 100% 本地隐私安全：呼吸与声学包络仅在设备本地内存中瞬时推演，绝不录制音频、绝不上传服务器。

4. Apple Health (HealthKit) 与标准 BLE 蓝牙心率外设同步

  • Apple Health (HealthKit) 专属卡片：位于首页 (Home) 与设置页 (Settings)，明确展示 4 项读取数据类型（心率、活动能量、步行+跑步距离、体能训练记录）与 3 项写入数据类型（间歇健走体能训练、活动能量、距离以闭合健身圆环），支持一键刷新与同步。
  • 蓝牙心率直连：支持直连任何符合 Bluetooth LE (0x180D) 开放标准协议 的蓝牙心率胸带、心率臂带与 Apple Watch 实时心率。

二、WalkFit Pro 会员订阅与恢复购买 (Subscriptions & Restore)

  • 一卡双通权益：升级 WalkFit Pro（月度订阅 com.walkfit.pro.monthly、年度订阅 com.walkfit.pro.yearly 或终身买断 com.walkfit.pro.lifetime）即可同时解锁白天健走全部 18 套高阶处方、5 款高定主题、3 款高阶表盘、50 项实时临床指标 以及夜间助眠剧场全部 高阶处方、整夜守护时长、大师和弦、自然声景与多日睡眠账本（应用内亦提供零扣费的「24 小时免费 Pro 体验」供完整试用）。
  • 如何恢复购买 (Restore Purchases)：更换设备或重装应用后，打开 WalkFit Pro 会员面板并点击底部 “恢复购买 (Restore Purchases)”，即可通过 Apple ID 免费恢复全部已购权益。
  • 管理或取消订阅：打开 iPhone “设置 (Settings)” -> 点击顶部 [Apple ID 姓名] -> “订阅 (Subscriptions)” -> 选择 “律动健走 (WalkFit)” 即可随时管理或取消自动续订。
